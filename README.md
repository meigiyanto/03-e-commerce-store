# E-Commerce Store

Proyek ini adalah aplikasi toko online modern yang dibangun dengan Next.js, TypeScript, Prisma, dan Tailwind CSS. Aplikasi ini dirancang untuk memberikan pengalaman belanja digital yang cepat, responsif, dan terstruktur, mulai dari pencarian produk, penambahan ke keranjang belanja, wishlist, hingga proses checkout dan pembayaran.

## Deskripsi Proyek

E-Commerce Store adalah platform belanja online yang bertujuan untuk memudahkan pengguna dalam menjelajahi produk, menambahkan item ke keranjang, serta menyelesaikan transaksi secara aman dan efisien. Proyek ini juga dilengkapi dengan area admin untuk mengelola produk dan operasi toko secara lebih terorganisir.

## Fitur Utama

- Tampilan katalog produk yang modern dan responsif
- Fitur keranjang belanja dan wishlist
- Alur checkout yang terintegrasi dengan pembayaran
- Halaman sukses setelah transaksi selesai
- Area admin untuk manajemen konten dan produk
- Arsitektur yang siap dikembangkan lebih lanjut untuk kebutuhan bisnis e-commerce

## Teknologi yang Digunakan

- Next.js
- React
- TypeScript
- Prisma
- Stripe
- Cloudinary
- Tailwind CSS

## Memulai Pengembangan

Instal dependensi:

```bash
npm install
```

Jalankan aplikasi dalam mode development:

```bash
npm run dev
```

Buka http://localhost:3000 untuk melihat aplikasi.
